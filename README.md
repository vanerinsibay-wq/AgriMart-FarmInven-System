# AgriMart + FarmInven System

## Overview
Integrated system:
- AgriMart (Flask Web + MySQL API)
- FarmInven (C# Desktop + SQLite Offline Mode)

## Tech Stack
- Flask
- MySQL
- .NET 6/8
- SQLite

## How to Run

### AgriMart
cd agrimart
source venv/bin/activate
python run.py

### FarmInven
cd farminven/FarmInven
dotnet run
